掲載内容はメーカー公式情報を確認したデータだけを使用しています。型番や製造時期によって内容が異なる場合があるため、最終確認は各メーカー公式情報と取扱説明書で行ってください。

発煙・焦げ臭い・異常発熱・漏電の疑いがある場合は、操作を続けず使用を中止してください。
