# 候補レビュー領域

このフォルダの内容は検索サイトの本番データではありません。

- `candidates.json`: 公式ページから機械的に抽出したエラーコード候補
- `discovered_sources.json`: 収集時に確認した公式ページと取得状況

## 重要

候補は自動では `data/errors.json` に入りません。正規表現による抽出なので、型番・年号・ページ内部の番号などが誤って候補になる可能性があります。

本番へ追加する前に、必ず次を確認します。

1. URLがメーカー公式ドメインであること
2. コードが本当にその家電のエラー／診断コードであること
3. 原因・対処が該当コードに対応していること
4. 型番やシリーズ限定の場合、その範囲を明記すること
5. 発煙・発火・漏電など安全上重要な案内を省略しないこと

確認後のみ `data/errors.json` に要約して追加します。追加すると既存の `Generate error pages` ワークフローが個別ページと sitemap を自動生成します。

## confidence

- `high`: ページ上で「エラーコード」「診断コード」等として直接検出した可能性が高い
- `medium`: エラー・故障・表示に近い文脈で検出
- `low`: 候補性はあるが誤検出の可能性が高い

`high` も未確認情報です。confidence は公開可否を意味しません。
